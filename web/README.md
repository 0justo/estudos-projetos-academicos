# Web — HTML, CSS e JavaScript

**2º semestre · Programação de Scripts**

Todos os arquivos abrem direto no navegador, sem instalar nada.

| Pasta | O que tem |
|---|---|
| [`exercicios-de-aula`](programacao-de-scripts/exercicios-de-aula) | Exercícios feitos em aula: estrutura HTML, listas, tabelas, imagens, CSS inline/interno/externo, páginas do sistema solar e scripts de JavaScript (`js0` a `js16`) com variáveis, condicionais, laços e eventos |
| [`atividade-02`](programacao-de-scripts/atividade-02) | Calculadora de área, fatorial, tabela de eletrodomésticos, troca de cores e cálculo de preço de venda |
| [`atividade-03`](programacao-de-scripts/atividade-03) | Mapa interativo dos países da América do Sul com eventos de clique (`addEventListener`) e uma calculadora com HTML, CSS e JS separados |
| [`prova-01`](programacao-de-scripts/prova-01) | Site de 4 páginas sobre a Proclamação da República com CSS externo |
| [`prova-02`](programacao-de-scripts/prova-02) | Conversor de prefixos, conversor de temperatura e cálculo de reajuste salarial |

Os arquivos `NOMES.txt` listam os integrantes das atividades em grupo.
