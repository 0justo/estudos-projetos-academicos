# Java — Estrutura de Dados

**3º semestre · Estrutura de Dados**

Estruturas implementadas do zero (sem usar as coleções prontas do Java) e exercícios que as aplicam.

| Pasta | Estrutura | O que tem |
|---|---|---|
| [`pilhas`](estrutura-de-dados/pilhas) | Pilha (LIFO) com vetor | `Pilha` (de `Object`) e `PilhaInt`; 8 exercícios: inverter valores, separar positivos e negativos, remover pares, separar múltiplos de 3 e restaurar a ordem original usando pilha auxiliar |
| [`filas`](estrutura-de-dados/filas) | Fila (FIFO) com vetor | `Fila` e `FilaInt`; exercícios de separação de valores e um **sistema de senhas** com atendimento normal e preferencial |
| [`lista-ligada`](estrutura-de-dados/lista-ligada) | Lista simplesmente ligada | `NodoLigado` e `ListaLigada`, com exercícios que combinam pilha, fila e lista ligada |
| [`aulas`](estrutura-de-dados/aulas) | Código das aulas | TAD (fração), POO (classes `Data` e `Horario`), pilha, fila e listas, na ordem do semestre |

## Como rodar

```bash
cd estrutura-de-dados/filas
javac *.java
java Exercicio4
```
