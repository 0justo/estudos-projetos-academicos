# TypeScript

## [Vitrolinha](vitrolinha)

**2º semestre · Engenharia de Software (trabalho P2)**

"Sua jukebox social. Resenhe, descubra, compartilhe." Aplicação web para avaliar e resenhar álbuns e músicas, integrada ao Spotify e ao Last.fm.

- **Stack:** Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Supabase (autenticação e banco PostgreSQL), PWA, deploy na Vercel
- **Banco:** migrações SQL em [`supabase/migrations`](vitrolinha/supabase/migrations)
- **Como rodar:** veja o [README do projeto](vitrolinha/README.md). As chaves de API não estão no repositório; copie `.env.local.example` para `.env.local` e preencha com as suas
- **Documentação de engenharia de software do projeto:** [`engenharia-de-software/vitrolinha-documentacao.pdf`](../engenharia-de-software/vitrolinha-documentacao.pdf)
