# PHP

**3º semestre · Linguagem de Programação IV**

## [Site ADS — Portas Abertas](site-ads-portas-abertas) (P1, em grupo)

Site para apresentar o curso de ADS a alunos do ensino médio no evento Portas Abertas da Fatec Jundiaí.

- **Quiz "Qual dev você é?"**: classifica o visitante em Front-end, Back-end, Dados ou Infra
- **Um minijogo por perfil** (cores, gráfico de funções, senha, vírus), com estado guardado em sessão PHP
- Páginas de áreas de atuação e tecnologias geradas a partir de **XML** ([`dados/areas.xml`](site-ads-portas-abertas/dados/areas.xml)) e **JSON** ([`dados/tecnologias.json`](site-ads-portas-abertas/dados/tecnologias.json))
- Layout com `include` de cabeçalho e rodapé, CSS e JavaScript próprios

**Como rodar:** com PHP instalado, `cd site-ads-portas-abertas` e `php -S localhost:8000`; depois abra <http://localhost:8000>.
