# Fatec Jundiaí — Análise e Desenvolvimento de Sistemas

Repositório com os códigos, projetos e trabalhos que desenvolvi no curso de **Análise e Desenvolvimento de Sistemas (ADS)** da Fatec Jundiaí "Deputado Ary Fossen".

**Carlos Eduardo Moreira dos Santos** · 3º semestre (2025 – 2026) · buscando estágio em desenvolvimento ou QA

O conteúdo está organizado **por linguagem e por área**. Cada pasta tem um README explicando o que tem dentro, de qual disciplina e semestre veio e o que pratiquei.
